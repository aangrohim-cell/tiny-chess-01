A 4 KB chess engine: 0x88 board, alpha-beta with iterative deepening to a fixed node budget, quiescence with check evasions, transposition table, killer moves, incremental material/PST evaluation and a pawn-shield term. `main.py` is the lzma-packed form of the readable source, made with `makefun compress`.

## Run it

```sh
python3 -P -s main.py
```
